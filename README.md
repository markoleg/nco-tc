# Лендинг Центру підготовки сержантського складу НГУ

Односторінковий статичний сайт, підготовлений для розміщення на GitHub Pages.

## Публікація на GitHub Pages

1. Створіть репозиторій на GitHub і завантажте в нього всі файли з цієї папки.
2. Відкрийте **Settings → Pages**.
3. У блоці **Build and deployment** виберіть **Deploy from a branch**.
4. Вкажіть гілку `main` і папку `/ (root)`, потім натисніть **Save**.

Сайт не потребує збірки, npm або серверної частини.
